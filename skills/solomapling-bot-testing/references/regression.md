# 回归与收尾

## 保留复现条件

复现记录包含：

- 待测版本或源码身份、目标类型及预期行为的来源。
- 目标角色、实际场景和必要前态；本次玩家会话及世界代次。
- 场景准备的实际增量，以及触发请求、操作结果、目标包或后态证据。
- 实际与预期的差异、正常规则核对结果、复现次数及仍未观察到的范围。

修复后重跑相同触发条件。若期间角色进度、场景、会话或目标类型有变化，记录新基线并解释比较范围；保留真实玩家活动，不用旧快照覆盖其资料。跨版本比较使用逻辑目标和行为，新的运行代次、scene_ref、对象 OID 或 session_id 从当前观察取得。

## 完成与停止

通过 [游戏交互技能](../../solomapling-game-interaction/SKILL.md) 核对本次操作和角色退出；通过 [脚本调试技能](../../solomapling-script-debug/SKILL.md) 核对脚本上下文与资源释放。取消请求、执行结果、真实停止、环境关闭和存档分别记录。

物品或角色进度属于验收目标时，按需正常退出、同 CID 重开并核对具体字段。关闭结果的通用保存标记只覆盖其声明范围。清理本次创建的隔离资源；对仍在运行或结果未知的工作保留标识和恢复线索。

目标行为已有充分证据时结束本轮，不为增加覆盖率继续改变场景。真实机器人或触发条件不存在时，该项保持未验；以桩完成的协议或实现检查只报告其实际边界。

## 问题报告

只列可复现缺陷、异常及未验项。缺陷可使用以下简短结构：

```text
问题：同场景准确点名后，目标未产生设计要求的响应。
预期：引用本次需求或当前实现路径。
复现：目标与前置条件；实际输入和原请求；等待及观察过程。
证据：操作结果；自身广播序号；目标响应或相关后态；缺失窗口说明。
影响：实际受影响行为与复现范围。
回归：修复版本、同场景复测结果及剩余未验项。
```

准备成功、端口连通、自己的发言已广播等正常事实留在原始证据中，不展开成正常检查列表。新建或更新外部缺陷记录沿当前会话已有授权执行，技能本身不增加对外操作权限。
