# 随机游戏行为的有界冒烟

随机路线、怪物活动和掉落通过真实游戏采样观察。本文接替 #326 删除的历史
`RandomizerTest` 全集必命中断言；有限样本不要求命中全部值、固定频次或固定收益。
当前北斗构建不运行旧 Cosmic 随机工具测试，也不为此另搭旧服务器。

## 开始前

记录源码提交、运行产物身份、环境、世界代次、实际场景引用与参与角色。
使用已授权的隔离环境或正常部署冒烟目标，沿项目的游戏交互/机器人验收技能确认
`game_capabilities` 和当前工具 schema，不沿用重启前的引用或手写工具全集。

选择已有支持的正常活动和可观察前提，例如合法交战后可能产生的普通掉落。
记录活动前的原生 HP、经验、背包及场景成员。材料准备、管理员生成物品和人工逐阶段
驱动单独记录，不算随机策略自动完成；没有所需角色、装备、怪物或可用活动时记未覆盖。

## 执行与采样

1. 通过已有活动入口开始一次最多120秒的正常行为；若活动本来就在运行，观察即可。
   使用当前支持的动作和规则，不修改随机种子、掉落率、时钟或策略来保证事件发生。
2. 开始、结束及约每15秒记录一次原生事实，单段最多10次采样。已有采集工具可用时
   记录对应文件与完整性；否则保存当前观察工具返回值。包/事件游标分开记录，缺口和
   截断保留，不把发送、处理器返回或模拟位置当成真人已经收到/播放。
3. 只对实际发生的事件核对来源和结果：同一目标的死亡、经验变化、生成地物的身份、
   归属和数量、已确认入包的物品。已存在物品的资产守恒和权限仍须严格成立。
   收益、碰撞、击杀或路线在某秒未出现，不作为失败条件。
4. 到预算后正常停止本次创建的活动；等待实际动作退出、占用和资源释放。若本次打开
   专用角色，再正常关闭会话并核退出；不影响其他活动或玩家，不另搭整套世界停启。

## 结果与证据

| 分类 | 判定 |
| --- | --- |
| 通过 | 本次实际覆盖的正常链路有来源明确、完整的原生前后态，且已正常收尾；结论仅限该样本。 |
| 产品失败 | 已满足前置，出现可定位的原生规则违例、异常成员/控制权、越权、资产异常或未释放资源；保留请求与后态查因。 |
| 未覆盖/不确定 | 随机前置未发生、样本不足、观察缺口或准备脚本错误；说明缺项，不自动升级为产品缺陷，也不写通过。 |

停止和释放未确认仍须跟进，不能归入随机性。报告保存版本、前置、操作/请求ID、
实际采样时间、原始输出位置、完整性、分类和收尾结果。复用已有有效证据，按源码影响
选择重验；文档或观测输出变化不触发全部玩法重跑。
