# 普通长距离追击与训练的有界隔离冒烟

本说明承接长距离运动、追击和击杀的真实观察。CI只保留交战预算传递、只读规划超时
分类和原工作真实排空合同，不要求角色沿固定路线抵达或在指定时刻击杀。

## 前置与版本

记录冻结提交、JAR、隔离容器、原数据库副本、世界代次、实际场景、角色CID和目标OID。
使用专用受管角色、正常合法武器和已支持的普通地面场景；管理员材料准备单独留证。
不固定随机种子、怪物位置或路线，不修改原生收益与控制权规则。

从当前源码的 `CombatActionModule.ENGAGE`、`NavigationActionModule.PLAN`、
`CombatTacticsControlModule.status()` 和实际工具能力取得入口与字段，不维护另一份API目录。
普通追击使用交战原deadline剩余及导航配置，风险预测窗口不作为完整追击距离上限。
跳跃避险、复杂AI及未支持覆盖仍按当前边界分别记录。

## 有限执行与观测

1. 找到同一实际场景内合法、原导航可达的普通远目标。先只读确认真实地形、活动区域、
   可信plan结果、预测时长及路线类型；超过4秒的完整接敌可作为本缺陷回归样本。
   若预算内没有合适目标，记未覆盖，不通过改坐标制造前置。
2. 使用原狩猎或交战入口开始一次正常活动，单次预算不超过120秒，最多采三个样本。
   不由Agent逐帧驱动。记录原交战work、战术指令、导航提供者预算、实际位移、
   原生攻击输出、目标HP及当前风险覆盖；输出与真人实际播放分别判断。
3. 观察正常追击是否继续推进，是否会因4秒预览而对原可达目标反复 `no_safe_approach`。
   若样本实际产生攻击或击杀，再核对应原生事实。没有击杀时按实际原因分类，
   不把某条随机路线或某秒击杀设为通过条件。
4. 正常停止本次活动，等待原交战、战术有限运动、短work与定时资源真实退出。
   已发生位移与伤害保留。若本次打开专用角色，再正常关闭并核原场景与scope释放。

完整训练日程另按既有有界训练流程记录拾取、容量、原生出售与返场。普通地物只沿
当前25px机会规则拾取，远处普通掉落没有入包本身不构成缺陷。不得为普通物品临时
补主动导航，或把管理员准备材料算作日程收益。

## 结果与冻结证据

- 通过：本样本的合法追击有真实输入/后态与准确收尾；实际发生的攻击、击杀及收益
  各自留证，结论限本次覆盖。
- 产品失败：已经满足可达、预算、活动约束与模型前置，却因错误预算截断反复停滞，
  或存在旧安排继续派发、错误取消、资产异常、原工作未释放。
- 未覆盖或不确定：前置未出现、真实目标变化、风险覆盖未知、读取缺口或预算不足。
  保留具体原因，不据随机事件未出现断言失败。
